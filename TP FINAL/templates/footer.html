La marca

DarkMatter es una marca de ropa urbana premium, de estética minimalista y estilo streetwear. Su logotipo e isotipo transmiten una imagen moderna, intensa y tecnológica.

El proyecto

Este proyecto es una app web completa desarrollada con HTML, CSS, JavaScript, Python y Flask. Incluye diseño visual, lógica de negocio, autenticación, base de datos y paneles para clientes y administradores.
