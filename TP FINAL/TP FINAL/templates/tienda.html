Bienvenido a DarkMatter

La marca

DarkMatter es una marca ficticia de ropa urbana con identidad premium, estética minimalista y una propuesta visual inspirada en el streetwear. El logotipo y el isotipo fueron pensados para transmitir una imagen moderna, intensa y tecnológica.

El proyecto

Este proyecto consiste en desarrollar una app web completa usando HTML, CSS, JavaScript y Python con Flask. Integramos diseño visual, lógica de negocio, autenticación, almacenamiento de datos y una experiencia para clientes y administradores.
