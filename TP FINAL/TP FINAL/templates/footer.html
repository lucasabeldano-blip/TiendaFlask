La marca

DarkMatter es una marca ficticia de ropa urbana con identidad premium, estética minimalista y una propuesta visual inspirada en el mundo del streetwear.

El proyecto

Este proyecto escolar consiste en crear una tienda con estilo propio, una experiencia completa para clientes y administradores, y una estructura funcional donde se integra una API externa para manejar productos.
